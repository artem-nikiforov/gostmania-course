# Логирование попыток теста в Google Таблицу

Каждая попытка прохождения итогового теста (Блок 5) отправляется в Google
Таблицу: кто, когда, какая по счёту попытка, что ответил на каждый вопрос,
верно ли, итоговый балл, сдал/не сдал.

**Главное свойство:** отправка никак не влияет на прохождение курса. Если
сеть недоступна, прокси блокирует Google, или скрипт на той стороне упал —
тест всё равно засчитывается, ничего не подвисает и не показывает ошибок
пользователю. Подробности — в комментарии к `logTestAttempt()` в
`js/app.js`.

---

## Шаг 1 — создать таблицу и вставить скрипт

1. Создай новую Google Таблицу (sheets.new).
2. Меню **Расширения → Apps Script**.
3. Удали содержимое редактора и вставь код ниже целиком.
4. Сохрани (значок дискеты или `Cmd/Ctrl+S`).

```javascript
// ── Гостемания: приём результатов итогового теста ──
// SHARED_SECRET должен ТОЧНО совпадать со значением
// GOOGLE_SHEET_SECRET в js/app.js
const SHARED_SECRET = 'gostemania-2026';
const SHEET_NAME = 'Ответы теста';

// Порядок колонок в таблице — держим фиксированным, чтобы
// в дальнейшем можно было спокойно менять текст вопросов,
// не переезжая колонками.
const FIELDS = [
  'timestamp', 'session_id', 'attempt', 'student_id', 'student_name',
  'score', 'total', 'passed',
  'q1_answer', 'q1_correct', 'q2_answer', 'q2_correct',
  'q3_answer', 'q3_correct', 'q4_answer', 'q4_correct',
  'q5_answer', 'q5_correct', 'q6_answer', 'q6_correct',
  'q7_answer', 'q7_correct', 'q8_answer', 'q8_correct',
  'q9_answer', 'q9_correct', 'q10_answer', 'q10_correct',
];

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    if (data.secret !== SHARED_SECRET) {
      return ContentService.createTextOutput('forbidden');
    }

    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);

    if (sheet.getLastRow() === 0) {
      sheet.appendRow(FIELDS);
      sheet.setFrozenRows(1);
    }

    const row = FIELDS.map(f => (data[f] !== undefined ? data[f] : ''));
    sheet.appendRow(row);

    return ContentService.createTextOutput('ok');
  } catch (err) {
    return ContentService.createTextOutput('error: ' + err.message);
  }
}
```

## Шаг 2 — задеплоить как веб-приложение

1. Кнопка **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. «Выполнять от имени»: **Я** (твой аккаунт).
4. «У кого есть доступ»: **Все** (иначе курс не сможет постучаться без
   авторизации через Google — доступ защищён отдельным секретным ключом
   `SHARED_SECRET`, а не правами Google-аккаунта).
5. **Развернуть** → подтверди разрешения (Google спросит доступ к таблице —
   это твой собственный скрипт, это ожидаемо).
6. Скопируй появившийся URL — он заканчивается на `/exec`.

## Шаг 3 — вписать URL в курс

Открой [js/app.js](js/app.js) и найди строку:

```js
const GOOGLE_SHEET_ENDPOINT = '';
```

Вставь туда скопированный URL:

```js
const GOOGLE_SHEET_ENDPOINT = 'https://script.google.com/macros/s/AKfycb.../exec';
```

Пока строка пустая — логирование полностью выключено (функция сразу
выходит), это безопасное состояние по умолчанию.

Если меняешь `SHARED_SECRET` в скрипте на что-то своё — обнови и
`GOOGLE_SHEET_SECRET` в `js/app.js` тем же значением.

## Шаг 4 — проверить

Пройди тест в браузере (или на GitHub Pages) до конца — нажми «Завершить
тест». В течение секунды-двух в таблице появится новая строка. Если
строки нет:

- проверь, что URL скопирован полностью и заканчивается на `/exec`;
- открой вкладку Network в devtools при прохождении теста — там будет
  запрос на `script.google.com`; статус там всегда будет "opaque"
  (это нормально для `no-cors`, ошибку так не увидеть) — ориентируйся
  на то, появилась ли строка в таблице;
- перепроверь, что `SHARED_SECRET` совпадает в обоих местах.

## Что в колонках

| Колонка | Значение |
|---|---|
| `timestamp` | время попытки (ISO, UTC) |
| `session_id` | случайный ID вкладки/захода — группирует попытки одного визита |
| `attempt` | номер попытки по счёту в рамках вкладки |
| `student_id` / `student_name` | если курс открыт из LMS и она передаёт SCORM `cmi.core.student_id/name` — заполнится автоматически; на GitHub Pages будет пусто |
| `score` / `total` / `passed` | верных ответов / всего вопросов / сдал ли (да·нет) |
| `qN_answer` | текст выбранного варианта(ов) по вопросу N (для нескольких верных — через `; `) |
| `qN_correct` | верно ли отвечен вопрос N |

## Ограничения, о которых стоит знать

- **Доступ «Все»** к веб-приложению означает, что теоретически кто угодно,
  зная URL, может отправить туда произвольные данные — их отсеет неверный
  `secret`, но сам факт долбёжки по URL никто не блокирует (rate-limit
  здесь не делали ради простоты). Для внутреннего обучающего курса это
  приемлемый риск; если понадобится — можно добавить проверку по IP или
  более сложный токен.
- **Корпоративная сеть.** Если курс открывается во внутренней сети
  компании и прокси блокирует исходящие запросы на домены Google — данные
  просто не будут доходить (без ошибок и заметного пользователю сбоя,
  ровно как и задумано). Стоит один раз проверить это на реальном
  рабочем месте после деплоя.
- **`no-cors` = нет подтверждения доставки.** Мы сознательно не проверяем,
  дошли ли данные — это и есть цена того, что отправка гарантированно не
  блокирует и не роняет курс. Если для этой таблицы важна 100%-я
  надёжность лога — есть смысл параллельно писать сводку (балл, сдал/не
  сдал) ещё и в `cmi.suspend_data` SCORM, что уже сделано отдельно от
  этого механизма.
